# Architecture Decision Records

One file per decision: `NNNN-short-title.md`. The summary table in
[`../ARCHITECTURE.md`](../ARCHITECTURE.md) §24.1 is the index of record; an ADR
here expands a decision that needed more context than a table row.

## Template

```md
# ADR-NNNN — Title

- Status: proposed | accepted | superseded by ADR-XXXX
- Date: YYYY-MM-DD

## Context

What forces are at play. What breaks if we choose wrong.

## Decision

The choice, stated in one paragraph.

## Consequences

What becomes easy, what becomes hard, what we now must never do.
```

# cc-web Design System

Single source of truth for the web UI's visual language. The theme lives entirely in
`apps/web/src/styles/index.css` (generated by shadcn-vue, style `reka-vega`, base color
`neutral`, CSS variables enabled). Do **not** add a custom theme layer — see
`apps/web/src/styles/app.css` for the note.

## Overview

| Aspect | Value |
| --- | --- |
| Framework | Tailwind CSS v4 (`@theme inline` tokens) + shadcn-vue (`reka-vega` style) |
| Font | Inter (Google Fonts, weights 400/500/600/700), `--font-sans`; headings reuse the same font |
| Base color | Neutral (grayscale surfaces) with a **red primary accent** |
| Color format | OKLCH in CSS variables; hex values below are approximations for reference only |
| Dark mode | `.dark` class on root; same token names, remapped values |

## Radius & Borders

Base radius `--radius: 0.45rem` (≈ 7.2 px), scaled into Tailwind tokens:

| Token | Value | Approx. px |
| --- | --- | --- |
| `rounded-sm` | `calc(var(--radius) - 4px)` | 3.2 px |
| `rounded-md` | `calc(var(--radius) - 2px)` | 5.2 px |
| `rounded-lg` | `var(--radius)` | 7.2 px |
| `rounded-xl` | `calc(var(--radius) + 4px)` | 11.2 px |

Border conventions:

- **Width**: 1 px everywhere (Tailwind default `border`); no 2 px borders in the UI kit.
- **Default color**: `--border` is applied globally via `* { @apply border-border }` in
  `@layer base`, so a bare `border` utility already picks up the theme color.
- **Buttons** render `border border-transparent` by default (invisible, reserves space);
  the `outline` variant switches to `border-border` (dark: `border-input`).
- **Badge** uses a full pill (`rounded-4xl`) instead of the radius scale.
- **Focus**: `focus-visible:ring-3 ring-ring/50` + `focus-visible:border-ring` on
  interactive elements; invalid fields tint to `border-destructive` with a
  `ring-destructive/20` ring.
- **Dark mode borders are alpha-based** (white at 10–15%), never solid grays.

## Sizing

Control heights follow a 4 px-based scale; `h-9` (36 px) is the default control height
shared by Button (default) and Input.

| Component / size | Height | Padding | Radius | Text |
| --- | --- | --- | --- | --- |
| Button `xs` | 24 px (`h-6`) | `px-2` | `rounded-md` | `text-xs` |
| Button `sm` | 32 px (`h-8`) | `px-2.5` | `rounded-md` | `text-sm` |
| Button `default` | 36 px (`h-9`) | `px-2.5` | `rounded-md` | `text-sm` |
| Button `lg` | 40 px (`h-10`) | `px-2.5` | `rounded-md` | `text-sm` |
| Button `icon` variants | 24/32/36/40 px square (`size-*`) | — | `rounded-md` | — |
| Input | 36 px (`h-9`) | `px-2.5 py-1` | `rounded-md` | `text-base` → `text-sm` at `md:` |
| Badge | 20 px (`h-5`) | `px-2 py-0.5` | pill (`rounded-4xl`) | `text-xs` |

- Icon sizing inside controls: 16 px (`size-4`) by default, 12 px (`size-3`) in `xs`
  sizes — applied automatically via `[&_svg:not([class*=size-])]`.
- Internal gap: `gap-1.5` (default/lg), `gap-1` (xs/sm).
- Button label weight: `font-medium`.
- Buttons get a subtle pressed state: `active:translate-y-px`.

## Extending

- Add components via the shadcn-vue CLI (config in `apps/web/components.json`) so they
  match `reka-vega` and land in `apps/web/src/components/ui/`.
- Always consume tokens (`bg-primary`, `text-muted-foreground`, `border-border`, …)
  instead of raw hex values; the OKLCH variables are the source of truth.
- Keep `app.css` layout-only; palette/type/radius changes go through the generated
  `index.css` token block.
